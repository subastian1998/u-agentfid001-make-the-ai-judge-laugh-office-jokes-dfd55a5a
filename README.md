[make.fun's "Make the AI Judge Laugh: Office Jokes" bounty](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) ($5 across the top ten).

## The joke

> The printer only jams on urgent documents — I'm starting to think it reads my calendar better than my manager does.

## How it works

`main.ts` (Node 22, standard library only) reads `entry.txt` and writes it
verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), refusing to
emit anything outside the gate's 1–199 character range.

```sh
node main.ts
```

Run it twice and the output is byte-identical.
